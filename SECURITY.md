# Security policy

This repository is a worked example with fictional content. A defect in the engines or the specification belongs to [`goat-transformers`](https://github.com/USAREUR-AF/goat-transformers); report it there.

## Reporting a vulnerability

**Do not open a public issue or pull request to report a vulnerability.**

**[Report a vulnerability privately](https://github.com/USAREUR-AF/goat-transformers-overlay-example/security/advisories/new)**

You can also open the reporting form from this repository's *Security* tab by selecting *Report a vulnerability*.

Reports are private and accessible to repository administrators, organization owners, security managers, the reporter, and collaborators explicitly added to the advisory. Reports remain private until an authorized maintainer publishes the advisory. See [GitHub's advisory permissions](https://docs.github.com/en/code-security/reference/permissions/repository-security-advisory) for details.

Include: a description of the issue and its impact; reproduction steps or a proof of concept; the affected commit; whether you have shared it elsewhere.

Use the same private channel if you find content in this repository that is not fictional: a field layout, name or value taken from a real format.

## What to expect

| Step | Target |
|---|---|
| Acknowledgement | 3 working days |
| Triage and severity | 7 working days |
| Fix or mitigation for a confirmed high or critical issue | 30 days, with a coordinated disclosure date agreed with you |
| Public advisory | when the fix is released, crediting you unless you prefer otherwise |

## Scope

In scope: the scripts and data files in this repository (`assemble.sh`, `check.sh`, `tools/`, `model/`, `packs/`). Out of scope: the library this example pins, and any overlay you build from this shape.

## Supported versions

The latest commit on `main` is supported.
